# Allpa · Marca v1

Dirección aprobada por Rodrigo: opción 02, alpaca de cuerpo entero. Originales vectoriales para revisión óptica, no evidencia de reconocimiento validado.

- `symbol-{forest,black,cream}.svg`: símbolo editable con un contorno Bézier.
- `lockup-{forest,black,cream}.svg`: imagotipo, letras convertidas a contornos.
- `app-icon.svg`: original cuadrado de 1024 unidades, sin máscara de plataforma.
- `index.html`: lámina y reducciones a tamaño CSS real (zoom 100 %).
- `fonts/Fraunces.ttf`, `fonts/OFL.txt`: fuente de Google Fonts y licencia SIL OFL.
- `build.py`: requiere Python y fontTools; busca la dependencia en `tmp/allpa-brand-tools` o en el entorno Python. Ejecutar desde la raíz del repositorio.

Procedencia: exploración raster generada en esta conversación, opción 02 seleccionada por el usuario; reconstrucción geométrica en SVG. Fraunces obtenida de https://github.com/google/fonts/tree/main/ofl/fraunces. No se copiaron símbolos de los benchmarks.

Mínimos propuestos: símbolo 32 px de alto; imagotipo 160 px de ancho. Protección: 1/4 de la altura visible del símbolo. Validar esos mínimos en el soporte final. El cuerpo completo es un rasgo de identidad aprobado; los andenes pertenecen al lenguaje gráfico del producto.
